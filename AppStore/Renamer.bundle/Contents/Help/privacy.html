Renamer Privacy Policy

Publisher: Oliver Wackenreuther
Effective date: November 4, 2026

Application data

Renamer does not collect, transmit, sell, rent, or share personal information, drawing information, named-object information, usage information, telemetry, or analytics.

It reads layer, block, dimension-style, linetype, table-style, and text-style information from the active AutoCAD drawing and processes rename instructions locally solely to perform user-requested operations. It does not use advertising, tracking, cloud processing, or third-party SDKs that receive application data.

Local storage

Renamer does not create application logs or automatically retain drawing information. If the user selects Save Script, the script is written only to the file and location selected by the user.

External links and support

Optional GitHub and LinkedIn links open only when selected, and no drawing information is sent by Renamer. Information voluntarily supplied for support is used only to respond to or diagnose the request and retained only as reasonably necessary. Users should remove confidential information from support materials.

Changes and contact

This policy will be updated before a future version begins collecting or transmitting application data. Privacy questions may be submitted through the support contact on the Renamer Marketplace listing.
