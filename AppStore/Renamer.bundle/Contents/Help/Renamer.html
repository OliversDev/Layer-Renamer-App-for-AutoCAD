Renamer for AutoCAD

Renamer batch-renames layers, blocks, dimension styles, linetypes, table styles, and text styles through one reviewable script.

Start

Open AutoCAD's standard Add-ins tab and select Renamer, or enter OW:Renamer.

Rename objects

  1. Choose an object-category tab and select one or more rows. Ctrl and Shift support multiple selection.
  2. Optionally filter the tab. Filtering is exact by default; use * as a wildcard. Each tab preserves its own filter and selection.
  3. Enter a prefix, suffix, or optional Find and Replace values.
  4. To assign an exact name, select one object and use Rename To (single object). This overrides the other rename options.
  5. Select Add To Script List. Switch categories and repeat as needed.
  6. Review or edit the combined script. Copy, save, clear, or select Rename to run it. Lines beginning with ; are comments.
Protected, reserved, anonymous, layout, and externally dependent records are not offered. Renamer validates generated names and checks conflicts within each object category. Manually entered lines run as written and remain the user's responsibility to review.

Generated commands

Renamer creates localized AutoCAD -RENAME commands for the selected category. Objects in different categories may use the same name. Before execution, Renamer warns only when the same source is repeated or multiple targets collide within the same category.

Data and files

Drawing information is processed locally. Renamer does not automatically save the drawing or create logs. Save Script writes only to the location selected by the user.
