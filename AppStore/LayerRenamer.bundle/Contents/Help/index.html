Layer Renamer for AutoCAD

Layer Renamer builds reusable AutoCAD rename scripts using prefix, suffix, find-and-replace, or exact-name rules. The generated script can also be edited manually.

Start the app

Open the Plug-Ins ribbon tab and select Layer Renamer, or enter OW:LayerRenamer at the AutoCAD command line.

Rename layers

  1. Select one or more layers in the grid. Use Ctrl or Shift for multiple rows.
  2. Optionally filter the list. Filtering is exact by default; use * as a wildcard. Selections remain selected while filtering.
  3. Enter a prefix and/or suffix, or use Find and Replace to change part of each selected name.
  4. To assign any exact name, select one layer and enter the result in Rename To (single layer). This field overrides the other rename options.
  5. Select Add To Script List.
  6. Repeat with other selected layers and rename options as needed.
  7. Review or manually edit the script, then copy, save, or select Rename to run it in the active drawing.
Layer 0, Defpoints, and externally dependent layers are not offered for renaming. Layer Renamer rejects invalid, duplicate, conflicting, or over-length names before changing the drawing. Keep current backups and review all previews before use on production drawings.

Generated script

Each generated layer rename creates one direct -RENAME command containing the current and resulting layer names. Generated commands are validated before they are added. Manually entered commands are run as written and are the user's responsibility to review.
