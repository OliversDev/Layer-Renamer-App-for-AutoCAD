Layer Renamer for AutoCAD

Layer Renamer safely previews and applies prefix, suffix, and find-and-replace rules to multiple drawing layers.

Start the app

Open the Plug-Ins ribbon tab and select Layer Renamer, or enter OW:LayerRenamer at the AutoCAD command line.

Rename layers

  1. Select one or more layers in the grid. Use Ctrl or Shift for multiple rows.
  2. Optionally filter the list. Partial text and the * wildcard are supported, and selections remain selected while filtering.
  3. Enter a prefix and/or suffix.
  4. Enable Find and Replace when part of the existing layer name should change. Enable Match case when required.
  5. Review the New Name preview column.
  6. Select RENAME and confirm.
Layer 0, Defpoints, and externally dependent layers are not offered for renaming. Layer Renamer rejects invalid, duplicate, conflicting, or over-length names before changing the drawing. Keep current backups and review all previews before use on production drawings.

Undo

A rename operation is committed as one AutoCAD transaction and can be reversed through AutoCAD's normal undo workflow while the drawing remains open.
