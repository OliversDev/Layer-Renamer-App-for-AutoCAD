Layer Renamer for AutoCAD

Layer Renamer previews prefix, suffix, and find-and-replace rules and builds a reusable AutoCAD rename script.

Start the app

Open the Plug-Ins ribbon tab and select Layer Renamer, or enter OW:LayerRenamer at the AutoCAD command line.

Rename layers

  1. Select one or more layers in the grid. Use Ctrl or Shift for multiple rows.
  2. Optionally filter the list. Filtering is exact by default; use * or ? as wildcards. Selections remain selected while filtering.
  3. Enter a prefix and/or suffix.
  4. Optionally enter text in Find and Replace to change part of the existing name.
  5. Review the Proposed Layer Name column, then select Add To Script List.
  6. Repeat with other selected layers and rename options as needed.
  7. Copy or save the read-only script, or select Rename to run it in the active drawing.
Layer 0, Defpoints, and externally dependent layers are not offered for renaming. Layer Renamer rejects invalid, duplicate, conflicting, or over-length names before changing the drawing. Keep current backups and review all previews before use on production drawings.

Generated script

Each staged layer creates one direct -RENAME command containing the current and proposed layer names. Because the script intentionally remains simple, a proposed name cannot already exist in the drawing.
