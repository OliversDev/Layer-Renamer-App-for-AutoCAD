# Changelog

## 2.0.0 — September 2, 2026

- Added prefix, suffix, case-insensitive find-and-replace, and exact single-layer rename methods.
- Added selection-preserving exact and `*` wildcard filtering.
- Added an editable script workspace with generated direct rename commands, copy, save, clear, and run actions.
- Added generated-name validation for invalid, empty, over-length, duplicate, and existing names.
- Added non-blocking pre-run warnings for duplicate destinations and repeated source layers while excluding comments and unrelated script content from analysis.
- Excluded layer 0, Defpoints, and externally dependent layers.
- Updated the interface to follow the Windows light or dark application theme.
- Added consistent themed confirmation and information dialogs.
- Preserved the bottom-left logo, GitHub, LinkedIn, author, License, Privacy, and Help access.
- Added AutoCAD 2026/.NET 8 and AutoCAD 2027/.NET 10 build targets.
- Added a dedicated Layer Renamer panel to AutoCAD's standard Plug-Ins ribbon tab.
- Added the two-layer LR application, Marketplace, ribbon, and Windows icon family.
- Added Marketplace bundle generation, Help, privacy, license, third-party notices, and store-listing content.
- Cleaned duplicate project images, unused designer metadata, unused WPF configuration, and missing optional resource dependencies.
