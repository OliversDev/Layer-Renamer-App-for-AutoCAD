# Renamer Privacy Policy

**Publisher:** Oliver Wackenreuther  
**Effective date:** November 4, 2026

Renamer does not collect, transmit, sell, rent, or share personal information, drawing information, named-object information, usage information, telemetry, or analytics.

The application reads layer, block, dimension-style, linetype, table-style, and text-style names and related display properties from the active AutoCAD drawing. It processes rename instructions locally solely to perform actions requested by the user. It does not require a publisher account and does not use advertising, tracking, cloud processing, or third-party SDKs that receive application data.

Renamer does not create application logs or automatically retain drawing information outside the active drawing. If the user selects **Save Script**, the script is written only to the file and location selected by the user. Optional GitHub and LinkedIn links open only when selected; Renamer does not send drawing information to those sites.

Information independently processed by Autodesk for Marketplace access, downloads, accounts, or AutoCAD is governed by Autodesk's policies and is not received by Renamer.

If a user voluntarily contacts the publisher, information supplied by the user is used only to respond to or diagnose the request, retained only as reasonably necessary, and not sold or used for advertising. Users should remove confidential information before supplying support materials. A user may request deletion of personal information voluntarily supplied for support through the support contact on the Marketplace listing.

This policy will be updated before any future version begins collecting or transmitting application data. Privacy questions may be submitted through the publisher support contact shown on the Renamer Marketplace listing.
